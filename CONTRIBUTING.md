# Contributing to PENOS

First off, thank you for considering contributing to PENOS! It's people like you who make PENOS such a great tool.

## How Can I Contribute?

### Reporting Bugs
* Check the existing issues to see if the bug has already been reported.
* If you can't find an open issue addressing the problem, open a new one.
* Include a clear title and description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements
* Open a new issue and describe the enhancement you'd like to see.
* Explain why this enhancement would be useful to most PENOS users.

### Pull Requests
* Fill in the required template.
* Do not include more than one fix/feature per pull request.
* Ensure your code follows the existing style and conventions.

## Development Setup
1. Clone the repository.
2. Install the required build tools (xorriso, squashfs-tools, qemu-user-static, etc.).
3. Run `./scripts/build_iso.sh` to generate the ISO.

## Open Source
PENOS is an open-source project. We welcome contributions from everyone.
